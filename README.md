# AI-Powered AUTOSAR/MISRA Violation Remediation & Git Patch Automation

## Objective

A Python-based AI-assisted automation framework for analyzing selected
AUTOSAR/MISRA static-analysis violations, generating remediation suggestions,
validating proposed changes, and preparing Git patches for human code review.

## Workflow

Static Analysis
→ Python Parser
→ Violation Analysis
→ AI-Assisted Remediation
→ Validation
→ Git Patch
→ Human Review

## Technology Stack

- Python
- AI/LLM
- C/C++
- AUTOSAR
- MISRA
- Git
- Jenkins
- pytest
